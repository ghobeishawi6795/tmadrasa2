# قدم ۳۷ (v20) — خلاصه‌ی وضعیت روی صفحه‌ی «تمرین»

بدون مایگریشن جدید — فقط از همون جدول `student_practice_results` (که با migration 025 ساخته شد) استفاده می‌کنه.

## چی اضافه شد
بالای صفحه‌ی تمرینِ دانش‌آموز، ۴ تا کارت خلاصه اضافه شد: «پاسخ داده‌شده (X از Y)»، «درست»، «غلط»، «باقی‌مانده» — جمعِ همه‌ی درس‌های قابل‌دسترسیِ همون دانش‌آموزه، نه فقط تب فعلی. `GET /api/student/practice-subjects` حالا به‌ازای هر درس، تعداد پاسخ‌داده‌شده/درست/غلطِ همون دانش‌آموز رو هم برمی‌گردونه (یک LEFT JOIN اضافه روی همون query قبلی، نه query جدا)، و فرانت‌اند این‌ها رو جمع می‌زنه. بعد از هر «بررسی پاسخ»، همین ۴ عدد بلافاصله (با یک fetch سبک، بدون رفرش کل صفحه) به‌روز می‌شن.

## راستی‌آزمایی
`node --check` روی بک‌اند و اسکریپت inline پنل دانش‌آموز، تمیز.
