# قدم ۳۴ (v18) — ادغام شاخه‌ی «بانک سؤال پیشرفته» با باگ‌فیکس‌های v16/v17

کاربر روی یک شاخه‌ی قدیمی‌تر (بلافاصله بعد از v15 / README-24) هفت قابلیت بزرگ بانک سؤال
را کامل ساخته بود (README-25 تا 33: متادیتا، نسخه‌بندی+پین‌کردن، جستجو/فیلتر/علاقه‌مندی،
قالب‌های آماده، تولید نسخه‌ی مشابه+سؤال مشابه+آمار+مهارت، سؤال HTML تعاملی دلخواه، بانک
عمومی+تأیید مدیر). این شاخه چون قبل از v16/v17 جدا شده بود، سه باگ‌فیکس اون دو نسخه رو
نداشت. این قدم فقط همون سه فیکس رو *روی* شاخه‌ی جدید (که کار بانک سؤالش کامل‌تره) پیاده
کرد — نه برعکس.

## فیکس‌های پورت‌شده از v16/v17
1. **`admin/classes.js`** — کوئری لیست کلاس‌ها دوباره `student_count`/`teacher_count` رو
   با ساب‌کوئری برمی‌گردونه.
2. **`admin/students.js`** — لیست دانش‌آموزان دوباره کلاس هر نفر رو نشون می‌ده (`LEFT JOIN`
   به `class_students`/`classes`، «بدون کلاس» برای دانش‌آموز بی‌کلاس).
3. **`admin/students.js` / `teachers.js` / `parents.js`** — هر سه دوباره پیش از ساخت کاربر،
   یوزرنیم تکراری رو با `errors.conflict(...)` چک می‌کنن؛ و اگه وسط زنجیره‌ی ساخت (کاربر →
   نقش → رکورد اختصاصی) هر مرحله شکست بخوره، همه‌ی چیزی که تا اون لحظه ساخته شده حذف
   می‌شه (rollback دستی، چون D1 این این‌سرت‌های به‌هم‌وابسته رو تو یک تراکنش اتمیک نمی‌بره)
   — یعنی یک یوزرنیم هیچ‌وقت برای همیشه «اشغال‌شده» گیر نمی‌کنه. ثبت‌ log هم best-effort
   شد (`.catch(() => {})`) تا خطای لاگ، یک ثبت‌نام موفق رو خطا نشون نده.
4. **`admin/index.html`** — دو تابع گمشده‌ی `loadClasses()`/`loadStudents()` اضافه شد
   (بدون این دو، دکمه‌های «تخصیص کلاس/درس» و «اتصال فرزند» ساکت خراب بودن).
5. **مسیر اطلاعیه‌ها** — هر ۵ فراخوانی (۳ تا در پنل مدیر، یکی والد، یکی دانش‌آموز) از
   `/api/announcements` به مسیر درست `/api/announcements/announcements` اصلاح شد.

## راستی‌آزمایی انجام‌شده قبل از پکیج‌کردن
- Syntax تمام فایل‌های `functions/api/**/*.js` (۸۱ فایل) با `node --check`.
- Syntax اسکریپت داخلی هر ۵ پنل (admin/teacher/student/parent/superadmin).
- تطبیق کامل تمام مسیرهای `api.get/post/put/delete(...)` در پنل معلم و مدیر با فایل‌های
  واقعی بک‌اند — همه درست بودن، هیچ مسیر گمشده‌ای پیدا نشد.

## هیچ migration جدیدی لازم نیست برای این قدم
همه‌ی مایگریشن‌های ۰۱۷ تا ۰۲۳ (بانک سؤال) دست‌نخورده از شاخه‌ی قدیمی اومدن — اگه هنوز
رو D1 نزدی، لیست کامل‌شون این‌هاست (باید به همون ترتیب اجرا بشن):

`020_fill_blank.sql`, `021_learning_skills.sql`, `022_custom_html.sql`,
`023_question_visibility.sql`.
