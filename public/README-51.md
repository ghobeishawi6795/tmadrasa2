# v51 (2026-09-15) — دور پنجم باگ‌یابی (بعد از v50)

## 🔴 گپ واقعی و مهم پیدا و اصلاح شد: کتابخانه اصلاً راهی برای امانت دادن کتاب نداشت
بک‌اند کتابخانه (ساخت کتاب، امانت دادن، برگشت) از قبل کامل و درست کار می‌کرد (توی دورهای قبل تست شد). ولی **هیچ‌جای رابط کاربری** — نه پنل مدیر، نه پنل دانش‌آموز — دکمه یا فرمی برای واقعاً «امانت دادن» یه کتاب به دانش‌آموز نداشت. مدیر فقط می‌تونست کتاب اضافه کنه و لیست موجودی رو ببینه؛ دانش‌آموز فقط می‌تونست کتاب‌ها و امانت‌های خودش رو (اگه از قبل ثبت شده بود) ببینه. یعنی این فیچر عملاً قابل استفاده نبود.

اضافه شد: توی «امکانات و مدیریت» مدیر، یه فرم «امانت دادن» (انتخاب کتاب موجود + دانش‌آموز + تاریخ سررسید اختیاری) و یه دکمه‌ی «برگشت» جلوی هر امانت فعال.
