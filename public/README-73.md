# دور بیست‌ونهم — قابلیت «ماندگاری ورود» + شروع باگ‌هانتینگ مرحله‌ای (۲۰۲۶-۰۹-۱۸) — v73

## قابلیت جدید: ماندگاری ورود (Persistent Login)
تا الان توکن نشست (session) توی `sessionStorage` مرورگر ذخیره می‌شد — یعنی با بستن کامل تب/برنامه پاک می‌شد، حتی اگه توکن سمت سرور هنوز ۳۰ روز اعتبار داشت. حالا:

- **پیش‌فرض روشن**: همه‌ی نقش‌ها (معلم، دانش‌آموز، ادمین، والد، سوپرادمین) بعد از بستن کامل مرورگر/برنامه هم لاگین می‌مانند، تا وقتی خودشان خارج شوند یا نشست ۳۰روزه منقضی شود.
- **کلید دست سوپرادمین**: صفحه‌ی جدید «تنظیمات» توی داشبورد سوپرادمین (`superadmin/index.html`) یه سوییچ داره که این رفتار رو برای کل سایت روشن/خاموش می‌کنه.
- وقتی خاموش باشه، برمی‌گرده به رفتار قبلی: ورود فقط برای همون تب، با بستن مرورگر باید دوباره رمز بزنی.

### چطور کار می‌کنه (فنی)
- جدول جدید `system_settings` (کلید/مقدار) + مایگریشن `051_system_settings.sql`، پرمیشن `system_settings.manage` فقط به `super_admin`.
- مسیر عمومی بدون نیاز به لاگین: `GET /api/public/settings` — چون این تصمیم باید قبل از لاگین گرفته بشه. فقط همین یه مقدار بولی رو برمی‌گردونه، هیچ اطلاعات حساسی نداره.
- مسیر سوپرادمین: `GET/PATCH /api/superadmin/settings`.
- `api.js`: `getSession()` حالا هر دو storage رو چک می‌کنه؛ `setSession()` بر اساس تنظیمات کش‌شده (در `localStorage`، آپدیت‌شونده از سرور موقع هر لود صفحه/صفحه‌ی ورود) بین `localStorage` و `sessionStorage` انتخاب می‌کنه.

## شروع دور جدید باگ‌هانتینگ مرحله‌ای (کاربر درخواست کرد)
پلن ۶ مرحله‌ای: (۱) پس ایستای کل ریپو (۲) شبیه‌سازی تراکنش روی SQLite واقعی (۳) پس IDOR/ownership (۴) ورودی خصمانه (۵) یکپارچگی UX (۶) پس تخصصی روی اکانت‌سوییچر و ریسپانسیو موبایل.

**مرحله ۱ (ایستا) کامل شد — بدون باگ جدی:**
- `node --check` روی هر ۱۱۹+۲ فایل بک‌اند: تمیز.
- تطبیق کامل مسیرهای API فرانت/بک‌اند: بدون مغایرت.
- توابع `onclick`: همه تعریف‌شده.
- پرمیشن‌ها: همه گرنت‌شده (یه false-positive بررسی و رد شد).
- کلاس‌های CSS یتیم: ۲۱ مورد بررسی، همه بی‌خطر.
- آی‌دی تکراری داخل صفحه: چند مورد بررسی، همه داخل شاخه‌های `if/else` مجزا (بدون تصادم واقعی).
- جدول‌های بدون `table-wrap`: ۲ مورد داخل پاپ‌آپ چاپ کارنامه (عمداً مستثنی)، ۲ مورد جزئی توی مودال «آمار سؤال» (ریسک کم، فیکس نشده — اگه خواستی بگو).

مرحله ۲ تا ۶ باقی مونده.
