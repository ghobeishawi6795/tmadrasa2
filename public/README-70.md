# دور بیست‌وششم — تناسب با موبایل: داشبورد دانش‌آموز (۲۰۲۶-۰۹-۱۸) — v70

## نتیجه بازبینی داشبورد دانش‌آموز
خبر خوب: بخش عمده‌ی این داشبورد (`student/index.html`) از قبل برای موبایل خوب ساخته شده بود — همه‌ی جدول‌ها توی `table-wrap` هستن، بوم نقاشی و پخش صدا و آی‌فریم‌های تمرین از قبل `width:100%` و `touch-action:none` داشتن (یعنی کشیدن با انگشت هم درست کار می‌کنه)، و پنجره‌های modal هم خودشون با عرض گوشی جمع می‌شن.

فقط **یک مورد واقعی** پیدا شد و درست شد:
- توی صفحه‌ی «پرونده و خدمات» (`student/services.html`)، جدول اطلاعات پرونده (نام/نام‌کاربری/کلاس/پایه/تولد/شناسه) همیشه ۲ ستونه بود، حتی روی گوشی‌های خیلی باریک — که باعث می‌شد مقادیر بلند (مثلاً اسم کامل) توی یه ستون تنگ بشکنه. الان زیر ۴۸۰ پیکسل به ۱ ستون تبدیل می‌شه.

(نکته‌ی جدول کارنامه‌ی چاپی داخل `index.html` رو عمداً دست نزدم — اون یه پنجره‌ی جدا برای چاپ روی کاغذه، نه بخشی از داشبورد، نیازی به ریسپانسیو‌شدن نداره.)
