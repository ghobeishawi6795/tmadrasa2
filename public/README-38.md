# قدم ۳۸ (v21) — «⚡ تمرین سریع»

بدون مایگریشن جدید — از همون endpoint های موجود (`practice-submit`) و داده‌ای که صفحه‌ی تمرین همین حالا برای نمایش لیست می‌گیره استفاده می‌کنه (یه fetch جدید هم لازم نبود).

## چی اضافه شد
دکمه‌ی «⚡ تمرین سریع» بالای صفحه‌ی تمرین (کنار عنوان صفحه): با کلیک، از همون سؤال‌های همین تب درس/فصل که در حال حاضر باز کردی، حداکثر ۱۰ تا رو به‌صورت تصادفی برمی‌داره و توی یک مودال، یکی‌یکی با نوار پیشرفت بالای صفحه نشون می‌ده. هر سؤال رو جواب می‌دی، فوری نتیجه رو می‌بینی (+ توضیح/پاسخ نمونه اگه بود)، «سؤال بعدی» می‌زنی. آخر دور، یه خلاصه (تعداد درست/نادرست/مجموع) نشون داده می‌شه و برمی‌گردی به لیست — که خلاصه‌ی بالای صفحه هم طبق معمول به‌روز شده.

اگه وسط کار «پایان زودهنگام» بزنه، چیزی که تا اون لحظه جواب داده رو از دست نمی‌ده (هر پاسخ همون لحظه‌ای که ثبتش می‌کنه ذخیره می‌شه، دقیقاً مثل حالت لیست معمولی) — فقط دور رو زودتر می‌بنده.

## راستی‌آزمایی
`node --check` روی اسکریپت inline پنل دانش‌آموز تمیز.
