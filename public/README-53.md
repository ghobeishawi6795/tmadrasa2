# v53 (2026-09-15) — دور هفتم باگ‌یابی (بعد از v52)

## 🟡 گپ پیدا و اصلاح شد: فیچرهای جدید هیچ اعلانی نمی‌فرستادن
پروژه یه قانون مشخص داره: «اعلان‌ها فقط از رویدادهای واقعی میان» (کامنت خود کد در `_shared/notify.js`) و این الگو قبلاً برای آزمون/تکلیف/نمره/حضورغیاب پیاده شده بود. ولی هیچ‌کدوم از فیچرهای batch دوم این کار رو نمی‌کردن — یعنی مثلاً وقتی یه معلم یه رکورد انضباطی برای دانش‌آموزی ثبت می‌کرد، والدینش هیچ اعلانی نمی‌گرفتن؛ باید خودشون می‌رفتن چک می‌کردن.

اضافه شد:
- ثبت رکورد انضباطی → اعلان به خود دانش‌آموز + والدینش
- تغییر وضعیت درخواست والد (تأیید/رد/تکمیل) → اعلان به همون والد
- ثبت درخواست جدید توسط والد → اعلان به همه‌ی مدیرهای مدرسه
- درخواست جلسه‌ی اولیا توسط والد → اعلان به معلم
- تغییر وضعیت جلسه (توسط معلم یا مدیر) → اعلان به طرف مقابل (یا هر دو، اگه مدیر تغییر داده)

یه تابع کمکی مشترک جدید (`getStudentUserIds`) به `_shared/notify.js` اضافه شد که کاربر دانش‌آموز + همه‌ی والدینش رو برمی‌گردونه، مشابه الگوی از قبل موجود برای کلاس‌ها. همه‌ی کوئری‌های جدید با شبیه‌سازی مستقیم روی schema واقعی تأیید شدن.

## نکته
اعلان‌های مالی (ثبت پرداخت) و برنامه‌ی امتحان هنوز اضافه نشدن — دور بعد.
