# دور بیست‌وهفتم — تناسب با موبایل: داشبورد مدیر (۲۰۲۶-۰۹-۱۸) — v71

## نتیجه بازبینی داشبورد مدیر
جدول‌ها همه از قبل درست بودن (`table-wrap` همه‌جا رعایت شده بود). موارد پیدا و اصلاح‌شده:

- توی `admin/operations.html`: ردیف‌های دوتایی فرم (تاریخ شروع/پایان سال تحصیلی، تولد/شناسه ملی، تماس‌های اضطراری، برنامه امتحان و…) همیشه ۲ ستونه بودن — روی گوشی باریک، ورودی‌های تاریخ/متن توی یه ستون ~۱۵۰ پیکسلی جمع و بریده می‌شدن. زیر ۴۸۰ پیکسل حالا تک‌ستونه می‌شن.
- توی `admin/index.html`: دو ردیف دکمه (ایمپورت CSV/ثبت دانش‌آموز، و تأیید/رد سؤال پیشنهادی معلم) هیچ‌کدوم `flex-wrap` نداشتن — روی گوشی خیلی باریک ممکن بود از عرض کارت بزنن بیرون. اضافه شد.

چیزهایی که از قبل خوب بودن و دست نخورد: انتخابگر تاریخ شمسی (استفاده در چند جای مختلف)، تقویم تعطیلات، همبرگری/سایدبار هر دو صفحه.

## داشبورد بعدی؟
فقط سوپرادمین می‌مونه (یک صفحه‌ست، `superadmin/index.html`) — همینو بریم یا فعلاً همین‌جا نگه داریم؟
