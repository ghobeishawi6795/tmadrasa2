# قدم ۳۵ (هنوز v18) — تب‌بندی بانک سؤال (درس + فصل) و نمایش دقیق فایل HTML وارد‌شده

## ⚠️ مایگریشن جدید لازم است: `024_bank_tabs_and_html_preview.sql`
این یکی رو هم مثل ۰۱۷ تا ۰۲۳ باید دستی رو D1 اجرا کنی:
```sql
INSERT INTO role_permissions (role_id, permission_id) SELECT (SELECT id FROM roles WHERE key = 'teacher'), id FROM permissions WHERE key IN ('subjects.create', 'subjects.update');
ALTER TABLE questions ADD COLUMN import_html TEXT;
ALTER TABLE questions ADD COLUMN import_style TEXT;
```
(می‌تونی همون کوئری «چک کردن مایگریشن‌ها» قبلی رو برای این دو ستون هم بزنی تا مطمئن بشی.)

## چی اضافه شد
1. **تب‌بندی بانک سؤال بر اساس درس** (بانک من): بالای جدول، به‌جای فیلد «شناسه درس»ی که فقط عدد می‌گرفت، حالا تب واقعی برای هر درس هست (ریاضی، فارسی، ...). «+ درس جدید» یه درس تازه برای کل مدرسه می‌سازه (همون جدول `subjects` که تو کلاس‌ها/برنامه‌ی هفتگی هم استفاده می‌شه)، و ✏️ کنار تب فعال اسمش رو عوض می‌کنه. همین قابلیت رو به پنل مدیر (صفحه‌ی «دروس») هم اضافه کردم (قبلاً فقط ساخت/حذف داشت، نه ویرایش نام).
2. **تقسیم‌بندی دستی با فصل، داخل هر تب درس**: زیر تب‌های درس، یه ردیف تب فصل نشون داده می‌شه — از روی همون فیلد «فصل» که موقع ساخت/ویرایش سؤال پر می‌کنی ساخته می‌شه (چیز جدیدی ذخیره نمی‌شه، فقط سازمان‌دهی بهتر). «+ فصل جدید» یه اسم می‌پرسه و به‌عنوان مقدار پیش‌فرض فیلد «فصل» برای سؤال بعدی می‌ذاره — به محض اینکه یه سؤال واقعی با اون اسم ساخته بشه، برای همیشه به‌عنوان یه تب دائمی می‌مونه.
3. **نمایش دقیق فایل HTML وارد‌شده به بانک آزمون**: قبلاً وقتی یه فایل HTML چندسؤالی برای آزمون وارد می‌کردی، فقط متن خام سؤال‌ها ذخیره می‌شد و ظاهر رنگی/طراحی‌شده‌ی فایل کامل از بین می‌رفت. حالا HTML اصلی هر بلوک سؤال (+ استایل مشترک فایل) هم ذخیره می‌شه، و کنار هر سؤالِ وارد‌شده از HTML یه دکمه‌ی 👁️ هست که پیش‌نمایش تمام‌صفحه‌ی دقیقاً همون ظاهر اصلی رو نشون می‌ده (فقط برای خودت، تو یک iframe کاملاً sandbox‌شده — بدون اجرای اسکریپت).

## نکته‌ی امنیتی مهم درباره‌ی مورد ۳
HTML ذخیره‌شده برای پیش‌نمایش، شامل پاسخ درست هم می‌مونه (چون تو فایل اصلی مشخص بود) — این کاملاً عمدیه چون این پیش‌نمایش فقط برای خودِ معلم تو بانک سؤالشه، هیچ‌وقت به دانش‌آموز نشون داده نمی‌شه.

## راستی‌آزمایی
همه‌ی فایل‌های بک‌اند (۸۱+ فایل) و اسکریپت هر ۵ پنل دوباره با `node --check` تست شدن، و تمام مسیرهای API پنل معلم/مدیر با بک‌اند مطابقت داده شد — چیزی گم نبود.
