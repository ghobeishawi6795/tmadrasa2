# v55 (2026-09-15) — دور نهم باگ‌یابی (بعد از v54)

## اصلاح جزئی
`admin/library.js`: حالا جلوی اینکه یه دانش‌آموز همون کتاب رو دوباره امانت بگیره در حالی که نسخه‌ی قبلی رو هنوز برنگردونده، گرفته می‌شه.

## بررسی گسترده‌ی این دور — چیز مهم دیگه‌ای پیدا نشد
همه‌ی endpoint های خودخدمت (self-service) دانش‌آموز/والد برای انضباط، برنامه‌ی امتحان، و مالی خط‌به‌خط بازخوانی شدن — درست و ایمن بودن.

یه مورد بررسی شد که در نگاه اول مشکوک به نظر می‌رسید: توی `admin/school.js`، چک‌کردن مجوز `school.update` از روی خواندن اطلاعات مدرسه (GET) برداشته شده بود. بعد از بررسی مشخص شد این عمدی و درسته — چون این مجوز فقط به مدیر داده می‌شه، ولی خواندن (نه تغییر) نام/لوگو/رنگ مدرسه باید برای همه‌ی نقش‌ها آزاد باشه (نه فقط مدیر). ذخیره/تغییرش (PATCH) همچنان محافظت‌شده‌ست.

فایل‌های `admin/schedules.js`، `admin/subjects.js`، `admin/teachers.js` هم بررسی شدن — همه‌ی تغییراتشون بهبودهای واقعی بودن (چک تداخل زمانی برنامه‌ی هفتگی، اعتبارسنجی ورودی‌های نام/رمز)، نه رگرسیون.
