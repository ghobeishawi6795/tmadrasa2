# قدم ۳۹ (v22) — رفع باگ «فصل جدید» + جایگزینی prompt() زشت

بدون مایگریشن جدید.

## باگ ۱: «+ فصل جدید» هیچ اتفاقی نمی‌افتاد
فصل یک موجودیت مستقل نیست — فقط متنیه که روی فیلد «فصل» یک سؤال می‌شینه، و تا وقتی هیچ سؤالی با اون فصل نباشه، اصلاً به‌عنوان تب نمایش داده نمی‌شه. قبلاً «+ فصل جدید» فقط فیلتر لیست رو روی اسم جدید می‌ذاشت و لیست خالی می‌موند — از دید معلم دقیقاً یعنی «هیچی نشد». حالا بلافاصله بعد از تایید اسم فصل، فرم «سؤال جدید» با همون درس و فصل از قبل پرشده باز می‌شه، به‌همراه یه پیام که بگه چرا (باید اولین سؤال این فصل رو ثبت کنی تا فصل به‌صورت دائم یک تب بشه).

## باگ ۲: کادرهای prompt() زشت با آدرس سایت
سه‌تا `prompt()` بومی مرورگر (درس جدید / ویرایش نام درس / فصل جدید) با یه `promptModal()` سفارشی جایگزین شدن که از همون کادر مودال قشنگ خود اپ استفاده می‌کنه — دیگه آدرس ورکرز دیده نمی‌شه. این تابع تو `modal.js` مشترکه، یعنی هر جای دیگه‌ی اپ (پنل ادمین/دانش‌آموز/والد و...) هم بخوایم بعداً به‌جای prompt() ازش استفاده کنیم، آماده‌ست.

## راستی‌آزمایی
`node --check` روی `modal.js` و اسکریپت inline پنل معلم، تمیز. لازم بود دقت بشه ترتیب resolve/close به‌هم نریزه (وگرنه کلیک روی «تأیید» مقدار واقعی رو گم می‌کرد) — درست شد.
