# دور بیست‌ودوم — رفع واقعی صفحه‌ی خالی «عملیات و امکانات» (۲۰۲۶-۰۹-۱۷) — v66

## علت واقعی (چیزی غیر از مجوز grade_periods بود)
`public/admin/operations.html` عنصر نام کاربر را با `id="name"` نوشته بود و عنصر نقش کاربر اصلاً id نداشت، در حالی که تابع مشترک `initShell()` (که همه‌ی صفحات نقش‌ها استفاده می‌کنند) بی‌قید و شرط این خطوط را اجرا می‌کند:

```js
document.getElementById("profileName").textContent = name;
document.getElementById("profileRole").textContent = ...;
```

چون این دو id در صفحه وجود نداشت، همان لحظه‌ی بارگذاری صفحه (قبل از اینکه اصلاً به بخش گرفتن اطلاعات کارت‌ها برسد) یک خطای جاوااسکریپت رخ می‌داد و کل اسکریپت متوقف می‌شد — به همین دلیل حتی نسخه‌ی تشخیصی v65 هم هیچ پیام خطایی نشان نداد؛ اسکریپت اصلاً به آن نقطه نمی‌رسید.

اصلاح مجوز `grade_periods` (migration 050) لازم بود ولی کافی نبود؛ این باگ کاملاً جداگانه و از قبل در همین فایل وجود داشت.

## تغییرات این نسخه
- `public/admin/operations.html`: `id="name"` → `id="profileName"`، و افزودن `id="profileRole"` به عنصر نقش. نسخه‌ی تشخیصی موقت (Promise.allSettled) هم نگه داشته شد تا اگر بعداً یک درخواست API دیگر خطا بدهد، به‌جای خالی ماندن صفحه، پیام دقیق آن نمایش داده شود.

## قدم بعدی
این نسخه را دیپلوی کنید و همان صفحه را دوباره باز کنید — باید حالا کارت‌ها (شامل «دوره‌های نمره‌دهی») به‌درستی نمایش داده شوند.
