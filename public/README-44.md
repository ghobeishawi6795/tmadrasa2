# v27 (2026-09-14) — رفع ۸ باگ گزارش‌شده توسط کاربر (+ چند مورد اضافه‌ی پیدا‌شده حین بررسی)

قبل از تحویل v26، کاربر ۹ مورد مشکوک گزارش داد. همه‌شون رو با دقت روی کد چک کردم:

**مورد ۱ («پاسخ سؤالات تعاملی در آزمون گم می‌شه»): در واقع باگ نبود.** انواع matching/ordering/drawing/coloring/audio_record/photo_upload اصلاً به‌عنوان نوع سؤالِ آزمون وجود ندارن (فقط ۷ نوع مجازه: چندگزینه‌ای/درست‌غلط/عددی/پاسخ‌کوتاه/تشریحی/جای‌خالی/HTML‌تعاملی). `answer_json` واقعاً هست ولی مال تکلیف‌هاست (match/drag_drop)، مسیر کاملاً جدا و درستی داره. سؤال HTML‌تعاملی می‌تونه هر تمرین تعاملی دلخواهی رو پیاده کنه و جوابش با ستون موجود `text_answer` درست ذخیره می‌شه. به‌احتمال زیاد قاطی با دبستان (که این انواع رو داره) شده بود.

باقی ۸ مورد همه واقعی بودن و الان فیکس شدن:

### ۲. 🔴 محدودیت زمانی واقعی روی آزمون
`exam-attempt.js` حالا روی هر `answer` هم زمان رو چک می‌کنه (نه فقط موقع `start`) — سقف زمانی هر Attempt، هر کدوم زودتر برسه: `شروع Attempt + duration_minutes` یا `end_at` خود آزمون. `submit` عمداً محدود نشده (چون فقط جواب‌های ذخیره‌شده رو می‌خونه و می‌بنده — محدودش کردن یعنی Attemptهایی که دیرکرد داشتن هیچ‌وقت نمره نمی‌گیرن).

### ۳. 🟠 بکاپ کامل شد (بیشتر از چیزی که گزارش شده بود)
۷ جدولی که گزارش دادی (`grade_periods`, `chapters`, `learning_skills`, `question_skills`, `school_holidays`, `notifications`, `user_roles`) + ۶ جدول دیگه که خودم پیدا کردم (`assignment_questions`, `submission_answers`, `submission_files`, `question_versions`, `assignment_attachments`, `student_practice_results`) — همه به بکاپ اضافه شدن. مهم‌ترینش `submission_answers` بود: جواب واقعی دانش‌آموزها به تکالیف چندسؤالی، که اصلاً هیچ‌جا بکاپ نمی‌شد.

### ۴. 🟠 ترتیب insert/validate بانک سؤال
هم توی ساخت (POST) هم ویرایش (PUT)، الان گزینه‌های چندگزینه‌ای (حداقل ۲ تا، دقیقاً ۱ گزینه‌ی درست) **قبل از** نوشتن روی دیتابیس چک می‌شن. دیگه هیچ ردیف یتیم/نیمه‌نوشته‌ای ساخته نمی‌شه.

### ۵. 🟠 جای‌خالی با پاسخ خالی
اگه یه سؤال جای‌خالی روی تصحیح خودکار باشه، الان `correct_text` خالی رد می‌شه (هم POST هم PUT) — یا باید پاسخ درست رو بنویسی یا نحوه‌ی تصحیح رو «دستی» بذاری.

### ۶. 🟠 ایمپورت گروهی CSV
همون الگوی rollback موجود توی `admin/students.js` (try/catch + پاک‌کردن جبرانی) روی `students-import.js` هم پیاده شد. یه ردیف که وسط کار fail بشه، دیگه یوزرنیم رو برای همیشه اشغال نمی‌کنه.

### ۷. 🟠 انتخاب دوره‌ی نمره
`getCurrentGradePeriod` الان واقعاً چک می‌کنه که «الان» بین `start_at` و `end_at` دوره هست یا نه (نه فقط جدیدترین `start_at`). **علاوه بر این، همین باگ رو عیناً — به‌صورت کپی‌شده و مستقل — توی `parent/grades.js` و `student/report-card.js` هم پیدا کردم** (هیچ‌کدوم از تابع مشترک استفاده نمی‌کردن)؛ هر دو الان به همون تابع مشترک وصل شدن.

### ۸. 🟡 قفل ثبت سوپرادمین
`register-superadmin.js` الان قبل از هر چیز چک می‌کنه که سوپرادمینی از قبل وجود نداره — اگه داشته باشه، با خطای صریح رد می‌شه، حتی اگه صفحه‌ی HTML حذف شده باشه ولی مسیر API هنوز روی سرور فعال باشه.

### ۹. 🟢 پاسخ درست چندگزینه‌ای در تمرین
هم توی صفحه‌ی تمرین معمولی هم «تمرین سریع»، الان بعد از جواب دادن به سؤال چندگزینه‌ای، متن گزینه‌ی درست هم مثل بقیه‌ی انواع نشون داده می‌شه.
