# دور بیست‌ودوم — نسخه‌ی تشخیصی برای صفحه‌ی خالی «عملیات و امکانات» (۲۰۲۶-۰۹-۱۷) — v65

## چرا این نسخه؟
با اینکه migration `050_grade_periods_permissions.sql` دستی روی D1 اجرا شد، صفحه‌ی `admin/operations.html` هنوز کاملاً خالی نمایش داده می‌شود. علتش این است که این صفحه ۹ درخواست API را با `Promise.all` همزمان می‌فرستد و اگر فقط یکی از آن‌ها خطا بدهد، کل صفحه خالی می‌ماند و پیام خطا فقط چند ثانیه به‌صورت toast دیده می‌شود (که معمولاً قبل از اسکرین‌شات گرفتن ناپدید می‌شود).

## تغییر این نسخه (فقط تشخیصی)
`public/admin/operations.html`: به‌جای `Promise.all`، از `Promise.allSettled` استفاده می‌کند و اگر هر کدام از ۹ درخواست شکست بخورد، به‌جای صفحه‌ی خالی، **نام دقیق درخواست ناموفق و پیام خطای آن را دائمی روی صفحه نمایش می‌دهد** (نه toast موقت).

## قدم بعدی
این نسخه را دیپلوی کنید، به همان صفحه بروید، و از پیام خطای قرمز/متنی که ظاهر می‌شود یک اسکرین‌شات بفرستید. با آن پیام دقیق، مشکل واقعی (کدام endpoint و چرا) مشخص و در نسخه‌ی بعدی برطرف می‌شود. هیچ تغییر دیگری در این نسخه اعمال نشده است.
