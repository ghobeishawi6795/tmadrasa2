# قدم ۳۱ — تولید نسخه‌ی مشابه، یافتن سؤال مشابه، آمار سؤال، اتصال به مهارت (مورد ۶)

چهار قابلیت جانبی که تو لیست مقایسه با هم گروه‌بندی شده بودن.

## ۱) تولید خودکار نسخه‌ی مشابه (🎲)
- `functions/api/_shared/question-variant.js` — منطق هسته عیناً از دبستان پورت شد (تشخیص یک عبارت محاسباتی صریح مثل «۵ + ۳» و تولید یک جفت عدد جدید با همون سطح سختی)، فقط ورودی/خروجی با ستون‌های مدرسه (`text`/`correct_numeric`/`correct_boolean`/`question_options`) تطبیق داده شد به‌جای `content_json` دبستان.
- محدود به سؤال‌های `numeric`، `multiple_choice`، `true_false` که یک عبارت محاسباتی صریح دارن — رو مسئله‌های کلامی کاری نمی‌کنه (عمداً، تا کلید پاسخ اشتباه تولید نشه).
- نتیجه همیشه یک **سؤال کاملاً جدید** تو بانک معلمه، نه جایگزینی سؤال اصلی — دقیقاً همون احتیاط دبستان (تا معلم قبل از استفاده مرورش کنه).

## ۲) یافتن سؤال مشابه
- موقع نوشتن سؤال جدید تو فرم، بعد از توقف تایپ، خودکار چک می‌کنه شبیه سؤالی تو بانک خودت هست یا نه (Jaccard روی کلمات نرمال‌شده‌ی فارسی، همون منطق دبستان).
- **یک تفاوت دامنه با دبستان**: دبستان این جستجو رو رو کل بانک مدرسه (همه‌ی معلم‌ها) انجام می‌داد، چون بانک عمومی داره. مدرسه هنوز بانک مشترک بین معلم‌ها نداره (مورد ۴، هنوز رو زمینه) — پس فعلاً این جستجو فقط رو بانک خود همون معلم انجام می‌شه. وقتی مورد ۴ ساخته بشه، طبیعتاً می‌شه گسترشش داد.

## ۳) آمار سؤال (📊)
- تعداد آزمونی که این سؤال توشون استفاده شده، تعداد کل پاسخ، درصد موفقیت، روند هفتگی، و تفکیک بر اساس کلاس.
- مثل مورد بالا، فقط رو آزمون‌های خود معلم حساب می‌شه (نه کل مدرسه).

## ۴) اتصال سؤال به «مهارت» یادگیری (🎯)
- دو جدول جدید: `learning_skills` (مهارت‌های خود معلم) و `question_skills` (اتصال چندبه‌چند).
- **عمداً ساده‌تر از دبستان**: دبستان یک ساختار سلسله‌مراتبی کامل داره (`parent_id`, `code`, `grade`, `subject`) به‌همراه یک داشبورد تحلیل نقاط‌ضعف کلاس بر اساس مهارت (`get-class-skill-analysis.js`). اینجا فقط خودِ اتصال ساده (نام + توضیح) پیاده شد — همون چیزی که تو لیست رتبه‌بندی اصلی خواسته شده بود ("اتصال سؤال به مهارت یادگیری"), نه یک داشبورد گزارش‌گیری کامل جدید. اگه بعداً خواستی گزارش نقاط‌ضعف بر اساس مهارت رو هم بسازیم، اون یک قدم جدا و بزرگ‌تره.
- حذف مهارت، حذف واقعی (hard delete) نیست — فقط `is_active = 0` می‌شه، تا اتصال‌های قبلی برای آمار/تاریخچه بی‌معنی نشن.

## چیزی که خارج از دامنه موند
- داشبورد گزارش نقاط‌ضعف کلاس بر اساس مهارت (بخش پیشرفته‌تر خود دبستان).
- نمودار گرافیکی برای آمار سؤال — فعلاً به‌صورت جدول ساده نمایش داده می‌شه.
