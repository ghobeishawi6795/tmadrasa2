# قدم ۲۸ — جستجو/فیلتر/علاقه‌مندی روی بانک سؤال (مورد ۳ از لیست مقایسه)

## چیزی که اضافه شد
- `database/migrations/019_question_favorite.sql` — ستون `is_favorite` (پیش‌فرض ۰).
- `functions/api/_shared/search-normalize.js` — عیناً از دبستان پورت شد (بدون تغییر): نرمال‌سازی متن فارسی برای جستجو (ك/ي عربی ↔ ک/ی فارسی، نیم‌فاصله، اعداد فارسی/عربی/لاتین).
- `functions/api/teacher/toggle-question-favorite.js` — endpoint جدید و جدا برای ستاره‌زدن. **عمداً از PUT سؤال استفاده نمی‌کنه** چون علاقه‌مندی محتوای آزمون نیست و نباید نسخه‌ی سؤال رو بالا ببره (طبق قدم ۲۶).
- `functions/api/teacher/questions.js` (GET): حالا query paramهای `search`، `type`، `difficulty`، `chapter`، `subject_id`، `favorite=1`، `tag` رو می‌پذیره. جستجو روی متن سؤال + فصل + مبحث + برچسب‌ها، با نرمال‌سازی فارسی.
- پنل معلم: یک نوار جستجو + فیلتر نوع/سختی + چک‌باکس «فقط علاقه‌مندی‌ها» + دکمه‌ی پاک‌کردن فیلترها، بالای بانک سؤال. هر سؤال یک دکمه‌ی ⭐/☆ داره.

## چیزی که خارج از دامنه موند
- فیلتر بر اساس فصل/مبحث به‌صورت dropdown (الان `chapter` تو API پشتیبانی می‌شه ولی تو UI هنوز فیلد جستجوی آزاد جایگزینش شده — چون فصل‌ها رشته‌ی آزادن، نه یک لیست ثابت؛ اگه بخوای بعداً یک dropdown از فصل‌های موجود بسازیم).
- بقیه‌ی لیست (مورد ۴ به بعد: بانک عمومی + تأیید مدیر، قالب‌های آماده، variant generator و...).
