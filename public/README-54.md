# v54 (2026-09-15) — دور هشتم باگ‌یابی (بعد از v53)

## تکمیل کارهای مونده از دور قبل
- **اعلان پرداخت شهریه:** حالا وقتی پرداختی ثبت می‌شه، دانش‌آموز و والدینش اعلان می‌گیرن.
- **اعلان برنامه امتحان:** حالا وقتی برنامه‌ی امتحان یه کلاس تنظیم/به‌روزرسانی می‌شه، همه‌ی دانش‌آموزان اون کلاس و والدینشون اعلان می‌گیرن.
- **audit log تغییر رمز شخصی:** تغییر رمز عبور خود کاربر (نه بازنشانی توسط مدیر، که قبلاً اضافه شده بود) هم حالا ثبت می‌شه.

با این‌ها، پوشش اعلان و audit-log برای همه‌ی فیچرهای batch دوم کامل شد.
