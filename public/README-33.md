# قدم ۳۳ — بانک عمومی + تأیید مدیر (مورد ۴، آخرین مورد از لیست مقایسه)

## چیزی که اضافه شد
- `database/migrations/023_question_visibility.sql` — ستون `visibility` روی `questions` (`private` | `pending` | `public`) + مجوز جدید `questions.moderate` (فقط مدیر).
- معلم هیچ‌وقت مستقیم نمی‌تونه سؤالش رو «عمومی» کنه — درخواست «عمومی» همیشه اول `pending` می‌شه؛ فقط مدیر می‌تونه تأیید (`public`) یا رد (`private`) کنه.
- ذخیره‌ی دوباره‌ی یک سؤال که از قبل عمومی/در-انتظار بوده (مثلاً فقط عوض‌کردن فصل) دوباره وارد صف تأیید نمی‌شه — فقط وقتی وضعیتش واقعاً از خصوصی به‌اشتراک‌گذاری‌شده تغییر کنه.
- `functions/api/teacher/questions.js` (GET): پارامتر جدید `scope=public` — بانک عمومی **کل مدرسه** رو نشون می‌ده (نه فقط سؤال‌های خودت)، ولی همیشه محدود به همون مدرسه.
- `functions/api/teacher/copy-public-question.js` — کپی یک سؤال عمومی به بانک خودت، به‌عنوان یک سؤال کاملاً مستقل و خصوصی (نسخه‌ی خودت عمومی‌بودن سؤال اصلی رو به ارث نمی‌بره).
- `functions/api/admin/pending-questions.js` + `functions/api/admin/moderate-question.js` — لیست سؤالات در انتظار + تأیید/رد، با ثبت در audit log.
- پنل معلم: تب «بانک من» / «🌐 بانک عمومی مدرسه»، تیک اشتراک‌گذاری تو فرم سؤال، نشان‌های وضعیت (عمومی / در انتظار تأیید).
- پنل مدیر: صفحه‌ی جدید «📝 تأیید سؤالات عمومی».

## یک باگ که موقع پورت پیدا و اصلاح شد (نه یک تصمیم جدید، رفع یک اشتباه)
کد خود دبستان برای نمایش بانک عمومی (`list-questions.js`) وقتی `own === 'public'` بود، اصلاً فیلتر `school_id` نمی‌ذاشت — یعنی ظاهراً سؤال‌های عمومیِ **همه‌ی مدرسه‌های رو پلتفرم دبستان** به هر معلمی نشون داده می‌شد، نه فقط مدرسه‌ی خودش. این با اصل همیشگی مدرسه (هر چیزی همیشه `school_id`-محدود) در تضاده. نسخه‌ی مدرسه این اشتباه رو تکرار نکرد — بانک عمومی همیشه محدود به همون مدرسه‌ست ("عمومی" یعنی «بین معلم‌های همین مدرسه»، نه «رو کل پلتفرم»).

## چیزی که خارج از دامنه موند
- ویرایش‌کردن سؤال دیگران از داخل بانک عمومی (نیازی نیست — کپی‌کردن به بانک خودت و بعد ویرایش همون کپی، همون نتیجه رو می‌ده، بدون پیچیدگی مالکیت مشترک)
- اعلان (نوتیفیکیشن) به معلم وقتی سؤالش تأیید/رد شد — فعلاً فقط با رفتن به فرم سؤال، نشان وضعیتش رو می‌بینه.

با این قدم، تمام ۷ موردِ لیست مقایسه با دبستان تکمیل شد.
