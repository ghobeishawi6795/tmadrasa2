# v28 (2026-09-14) — نمایش «ضعیف‌ترین فصل‌ها» (مورد ۴ از صف تأییدشده)، بدون مایگریشن جدید

آخرین مورد از صف ۴موردی که بعد از فیچر تمرین تأیید شده بود: حالا برای هر نقش (دانش‌آموز/والد/معلم) فصل‌هایی که دانش‌آموز در بخش تمرین بیشترین نیاز به تکرار دارد نشون داده می‌شه.

### منطق مشترک (`_shared/practice.js`)
تابع جدید `getWeakestChapters` روی `student_practice_results` (فقط نتایج تصحیح‌خودکار، `is_correct IS NOT NULL`) گروه‌بندی بر اساس `subject_id` + `questions.chapter` انجام می‌ده و بر اساس درصد درستی صعودی مرتب می‌کنه. برای جلوگیری از قضاوت زودهنگام (مثلاً یک حدس اشتباه)، یک فصل فقط وقتی نشون داده می‌شه که حداقل ۳ سؤال از اون جواب داده شده باشه (`WEAK_CHAPTER_MIN_ATTEMPTS`).

### دانش‌آموز
اندپوینت جدید `GET /api/student/practice-weak-chapters` — بالای صفحه‌ی تمرین، زیر کارت‌های خلاصه، تا ۵ فصل ضعیف نشون داده می‌شه (اگه داده‌ای نباشه، کارت اصلاً نمایش داده نمی‌شه). بعد از هر پاسخ، همراه با بقیه‌ی خلاصه‌ها رفرش می‌شه.

### والد
اندپوینت جدید `GET /api/parent/practice-weak-chapters?student_id=` — توی صفحه‌ی «وضعیت تحصیلی»، بالای جدول نمرات هر درس. از همون مجوز `grades.view` استفاده می‌کنه (نه `practice.use` که مخصوص دانش‌آموزه) و مالکیت فرزند رو با `assertParentOwnsStudent` چک می‌کنه.

### معلم
اندپوینت جدید `GET /api/teacher/practice-weak-chapters?student_id=&class_id=&subject_id=` — پایین صفحه‌ی «نمرات»، برای هر دانش‌آموزِ کلاس/درسِ انتخاب‌شده یک دکمه‌ی «مشاهده» که یک مودال با فصل‌های ضعیف همون دانش‌آموز توی همون درس باز می‌کنه. مالکیت دقیقاً با همون تابعی چک می‌شه که ثبت نمره ازش استفاده می‌کنه (`assertTeacherCanGradeStudent`) — یعنی معلم فقط برای دانش‌آموزهایی که واقعاً توی اون کلاس/درس تدریس می‌کنه این رو می‌بینه، و محدود به همون یک درسه (نه همه‌ی درس‌های دانش‌آموز).
