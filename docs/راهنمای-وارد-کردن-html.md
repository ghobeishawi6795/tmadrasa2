# راهنمای وارد کردن سؤال/تکلیف از فایل HTML

این قابلیت به معلم اجازه می‌ده یه فایل HTML که با کمک هوش مصنوعی (طبق یه قالب ثابت) ساخته شده رو آپلود کنه، و اپ خودش سؤال‌ها رو به **بانک سؤال آزمون** یا **بانک تکلیف** اضافه کنه.

محل استفاده: پیشخوان معلم → «بانک سؤال» → دکمه‌ی «📥 وارد کردن از HTML».

---

## مهم‌ترین نکته قبل از هر چیز

**نام درس‌ها (`data-subject`) باید دقیقاً همون چیزی باشه که تو خود مدرسه ثبت شده** (مثلاً «علوم»، نه «علوم تجربی» اگه تو سیستم فقط «علوم» ثبت شده). اگه اسم مچ نشه، همون آیتم رد می‌شه (بقیه‌ی آیتم‌ها مشکلی پیدا نمی‌کنن).

**کلاس مقصد** فقط موقع آپلود، یه‌بار برای کل فایل انتخاب می‌شه (نه داخل خود HTML) — یعنی هر فایل رو برای یه کلاس مشخص آپلود کن.

---

## پرامپت آماده (این رو عیناً به هوش مصنوعی بده)

```
یک فایل HTML برای [نام درس] [شماره یا نام درس/فصل کتاب] بساز که شامل [تعداد] سؤال/تکلیف باشه،
مناسب برای دانش‌آموزان [پایه تحصیلی].

فقط و فقط از این ساختار HTML استفاده کن، بدون هیچ چیز اضافه (بدون <html>، <head>، <style>، توضیح اضافه):
هر سؤال/تکلیف باید داخل یک <div class="question" ...> جدا باشه، دقیقاً با یکی از این ۹ الگو:

۱) چندگزینه‌ای (برای بانک آزمون):
<div class="question" data-type="multiple_choice" data-target="exam" data-subject="نام درس">
  <p class="q-text">متن سؤال</p>
  <ul class="q-options">
    <li data-correct="false">گزینه غلط</li>
    <li data-correct="true">گزینه درست</li>
    <li data-correct="false">گزینه غلط</li>
  </ul>
</div>

۲) درست/غلط (برای بانک آزمون):
<div class="question" data-type="true_false" data-target="exam" data-subject="نام درس">
  <p class="q-text">یک جمله که درست یا غلط است</p>
  <p class="q-answer">true</p>  <!-- یا false -->
</div>

۳) عددی (برای بانک آزمون):
<div class="question" data-type="numeric" data-target="exam" data-subject="نام درس">
  <p class="q-text">یک سؤال با پاسخ عددی</p>
  <p class="q-answer">۱۲</p>
</div>

۴) پاسخ کوتاه (برای بانک آزمون، تصحیح دستی):
<div class="question" data-type="short_answer" data-target="exam" data-subject="نام درس">
  <p class="q-text">سؤال با پاسخ یک/دو کلمه‌ای</p>
  <p class="q-answer">پاسخ نمونه (اختیاری)</p>
</div>

۵) تشریحی (برای بانک آزمون، تصحیح دستی):
<div class="question" data-type="long_answer" data-target="exam" data-subject="نام درس">
  <p class="q-text">سؤالی که نیاز به توضیح داره</p>
</div>

۶) تطبیق دو ستون (تکلیف تعاملی، خودکار تصحیح می‌شود):
<div class="question" data-type="match" data-target="assignment" data-subject="نام درس" data-title="عنوان تکلیف" data-due-days="7">
  <p class="q-instructions">توضیح کوتاه برای دانش‌آموز</p>
  <ul class="q-pairs">
    <li data-left="آیتم سمت راست" data-right="آیتم متناظرش"></li>
    <li data-left="آیتم دوم" data-right="جفتش"></li>
    <!-- حداقل ۲، حداکثر ۱۰ جفت -->
  </ul>
</div>

۷) دسته‌بندی/کشیدنی (تکلیف تعاملی، خودکار تصحیح می‌شود):
<div class="question" data-type="drag_drop" data-target="assignment" data-subject="نام درس" data-title="عنوان تکلیف" data-due-days="7">
  <p class="q-instructions">توضیح کوتاه</p>
  <ul class="q-buckets">
    <li>نام دسته اول</li>
    <li>نام دسته دوم</li>
  </ul>
  <ul class="q-items">
    <li data-bucket="0">آیتمی که باید تو دسته اول بره</li>
    <li data-bucket="1">آیتمی که باید تو دسته دوم بره</li>
    <!-- عدد data-bucket از صفر شروع می‌شود؛ حداقل ۲، حداکثر ۱۵ آیتم -->
  </ul>
</div>

۸) ضبط صدا (تکلیف، تصحیح دستی — مناسب خواندن شعر/متن با صدای بلند):
<div class="question" data-type="audio" data-target="assignment" data-subject="نام درس" data-title="عنوان تکلیف" data-due-days="5">
  <p class="q-instructions">مثلاً: این شعر را با صدای بلند بخوان و ضبط کن</p>
</div>

۹) نقاشی (تکلیف، تصحیح دستی):
<div class="question" data-type="draw" data-target="assignment" data-subject="نام درس" data-title="عنوان تکلیف" data-due-days="5">
  <p class="q-instructions">توضیح نقاشی</p>
</div>

(دو نوع تکلیف دیگر هم هستند اگر لازم شد: data-type="photo" برای گرفتن عکس، و data-type="text" برای نوشتن متن — ساختارشان دقیقاً مثل audio/draw است، فقط data-type فرق می‌کند.)

قوانین:
- هر عدد/تاریخ را با رقم انگلیسی بنویس نه فارسی (مثلاً 12 نه ۱۲).
- برای چندگزینه‌ای دقیقاً یک گزینه data-correct="true" داشته باشد.
- برای بچه‌های ابتدایی، از سؤال‌های متنوع (نه فقط چندگزینه‌ای) و زبان ساده استفاده کن — تطبیق و دسته‌بندی برایشان جذاب‌تر است.
- data-subject در همه‌ی موارد باید دقیقاً "نام درس" باشد که من مشخص کردم (تغییرش نده).
- خروجی فقط همین div های question پشت سر هم باشد، هیچ متن اضافه‌ای قبل یا بعدشان ننویس.
```

جای `[نام درس]`, `[شماره یا نام درس/فصل کتاب]`, `[تعداد]`, `[پایه تحصیلی]` رو با مشخصات خودت پر کن، و کتاب/متن درس رو هم به هوش مصنوعی بده.

---

## بعد از گرفتن فایل از هوش مصنوعی

۱. خروجی رو تو یه فایل با پسوند `.html` ذخیره کن (هر ادیتور متنی، حتی نوت‌بوک گوشی، کافیه).
۲. برو پیشخوان معلم → «بانک سؤال» → «📥 وارد کردن از HTML».
۳. فایل رو انتخاب کن؛ اگه تو فایل تکلیف (match/drag_drop/audio/draw/...) هم هست، کلاس مقصد رو انتخاب کن.
۴. «وارد کردن» رو بزن — نتیجه (چند مورد اضافه شد، چند مورد و به چه دلیل رد شد) نمایش داده می‌شه.

اگه موردی رد شد، معمولاً یا اسم درس مچ نشده یا یکی از فیلدهای لازم (مثل گزینه‌ی صحیح) رو کم داشته — متن دلیل رد شدن دقیقاً می‌گه مشکل چیه.
