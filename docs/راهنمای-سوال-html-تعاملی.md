# راهنمای سؤال «HTML تعاملی دلخواه»

این نوع سؤال به معلم اجازه می‌ده یه فایل HTML/CSS/جاوااسکریپت **کاملاً دلخواه** (معمولاً ساخته‌شده با کمک هوش مصنوعی) رو مستقیم به‌عنوان یک سؤال آزمون اضافه کنه — یک بازی، شبیه‌سازی، یا هر تمرین تعاملی دیگه، نه فقط قالب‌های ثابتی که مدرسه از قبل می‌شناسه.

محل استفاده: پیشخوان معلم → «بانک سؤال» → «+ سؤال جدید» → نوع «HTML تعاملی دلخواه».

---

## چطور کار می‌کنه (و چرا امنه)

کدی که پیست می‌کنی، داخل یک قاب کاملاً ایزوله (`iframe sandbox="allow-scripts"`) اجرا می‌شه — یعنی جاوااسکریپتش واقعاً کار می‌کنه، ولی این قاب:
- هیچ دسترسی‌ای به کوکی/نشست ورود دانش‌آموز به مدرسه نداره
- نمی‌تونه صفحه رو ریدایرکت کنه یا پنجره‌ی جدید باز کنه
- کاملاً از بقیه‌ی سایت جداست

**⚠️ یک محدودیت واقعی که باید بدونی:** چون نمره از کد سمت مرورگر خودِ فایل میاد (نه از یک کلید پاسخ سمت سرور مثل بقیه‌ی سؤال‌ها)، این نوع سؤال **همیشه نیازمند تصحیح دستی**‌ه — حتی اگه فایل خودش یک نمره نشون بده، دانش‌آموزی که بلد باشه می‌تونه از طریق ابزار توسعه‌دهنده‌ی مرورگر اون نمره رو دستکاری کنه. این محدودیت ذاتیِ هر روشیه که کد دلخواه رو تو مرورگر اجرا می‌کنه؛ برای همین این نوع سؤال هیچ‌وقت خودکار نمره نمی‌ده، فقط چیزی که فایل گزارش می‌ده رو به‌عنوان نقطه‌ی شروع برای تصحیح دستی معلم نشون می‌ده.

---

## تنها قانونی که فایل باید رعایت کنه

هر جایی که فایل خودش نمره/نتیجه رو محاسبه و نمایش می‌ده (مثلاً یک تابع `finish()` یا آخر بازی)، باید این خط رو هم اجرا کنه:

```js
window.parent.postMessage({ type: 'homeworkAnswer', value: نمره_یا_نتیجه }, '*');
```

`value` می‌تونه هر چیزی باشه (عدد، رشته) — همون چیزیه که تو صف «تصحیح دستی» معلم نشون داده می‌شه. بقیه‌ی فایل (ظاهر، انیمیشن، بازی، هرچی) کاملاً دست خودته و هیچ محدودیت قالبی نداره.

اگه این خط رو نذاری، دانش‌آموز می‌تونه تمرین رو کامل انجام بده، ولی هیچ‌چیزی به سیستم گزارش نمی‌شه — از دید معلم انگار پاسخی ثبت نشده.

## پرامپت آماده (این رو عیناً به هوش مصنوعی بده)

```
یک فایل HTML مستقل برای [موضوع تمرین] بساز، مناسب برای دانش‌آموزان [پایه تحصیلی].
تمام CSS و جاوااسکریپت باید داخل همون فایل باشه (بدون فایل خارجی).
هر جا که نمره یا نتیجه‌ی نهایی رو محاسبه/نمایش می‌دی، این خط جاوااسکریپت رو هم اجرا کن:

window.parent.postMessage({ type: 'homeworkAnswer', value: <نمره یا نتیجه> }, '*');
```

---

## نکته‌ی جانبی

اگه فایلی از قبل داری که این خط رو نداره (مثلاً چیزی که قبلاً جداگانه ساختی)، کافیه همین یک خط رو دستی به انتهای تابع نمره‌دهی‌ش اضافه کنی — نیازی به تغییر ساختاری نیست.
